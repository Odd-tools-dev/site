Odd Tools adds an **Odd Tools** tab to the Revit ribbon. It follows the Revit theme: light or dark (the dark theme exists from Revit 2024).

<Ribbon />

| Panel | Buttons | Page |
|---|---|---|
| **General** | <Icon name="about" /> About · <Icon name="options" /> Options · Documentation · Report a bug | [Options](../options/) |
| **Family management** | <Icon name="export" /> Bulk Export · <Icon name="import" /> Bulk Import · <Icon name="rename" /> Rename | [Export](../../familles/export/) · [Import](../../familles/import/) · [Rename](../../familles/renommer/) |
| **Worksets** | <Icon name="worksets" /> Worksets · <Icon name="rules" /> Sort | [Worksets](../../sous-projets/gerer/) · [Sort](../../sous-projets/ranger/) |
| **Toposolid** | <Icon name="projectedarea" /> Projected Topo Area | [Projected Topo Area](../../topo/surface-projetee/) |
| **Sales plans** | <Icon name="plans" /> Generate plans | [Generate plans](../../plans/generer/) |

The **About** button shows the installed version, your licence type and, for store versions, your licence code (with a copy button).

<Aside type="tip" title="Help with F1">
Hover a ribbon button and press **F1**: the page of this documentation about that tool opens. The same shortcut works inside an open tool window. The **About** button also has a link to the documentation.
</Aside>

Only installed panels appear. You can also hide some in [Options](../options/).
