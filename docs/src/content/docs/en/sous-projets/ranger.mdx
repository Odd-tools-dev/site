Create **rules** that sort elements into worksets: by category, family name, type, instance or type parameters. Rules are applied **in order** and can be **saved as configurations**.

<Aside>
Only elements **already in a user workset** are processed. Elements in Revit's own worksets (views, families, standards) are never touched, nor those **borrowed by another user**. Collaboration must be enabled (**Worksets** button).
</Aside>

<Win name="rules" alt="Sort into worksets window" />

## Rules

Each table row is a rule: a name, **conditions** and a **target workset**. Rules **run one after the other, from top to bottom**. An element matching several rules ends up in the workset of the **last** one: put general rules at the top and special cases below. Use **Move up / Move down** to change the order, the **On** box to set a rule aside.

An element that no rule matches is not moved.

A **⚠** in the **Elements** column (after **Preview…**) means some of the rule's elements are taken over by a rule placed lower.

**Example**: rule 1 sorts all walls into “ARC_Walls”; rule 2 (category = Walls **AND** type contains “50”) takes them over and moves them into “GC”.

<Win name="rules-table" alt="Rules table" />

## Conditions

A rule holds conditions joined by **AND** (all true) or **OR** (at least one). A **group** can contain other groups: `category = Walls AND (family starts with ARC_ OR family starts with STR_)`.

| Field | Content |
| --- | --- |
| **Category** | The element's category. |
| **Family** | Family name. |
| **Type (name)** | Type name. |
| **Instance / type parameter** | Value of a parameter, entered by name. |
| **Level** | The element's level. |

Operators: equals, is not, contains, does not contain, starts with, ends with, regular expression, is empty, is not empty. Case is ignored.

## Target workset

Pick a workset of the project or **type a new name**: it will be created when applying.

To create a rule, click **+ Add a rule**: it stays a **draft** until you click **Add to list** (it is neither applied nor counted before).

<Win name="rules-new-editor" alt="New rule, not in the list yet" narrow />

## Scope, preview, apply

- **Scope**: whole project, active view or selection.
- **Preview…**: shows how many elements will move to each workset, without changing anything.
- **Apply** / **Apply and close**: moves the elements in a single operation, undoable with **Ctrl+Z**.

<Win name="rules-preview" alt="Sorting preview" />

## Configurations

Rules are **saved** in configurations (**+ New**, **Save**, bin), **imported** and **exported** as `.json`. **● modified** means the rules differ from the saved configuration; the window offers to save on close. Choosing a configuration **replaces** the displayed rules.
